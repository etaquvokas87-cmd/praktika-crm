ПРАКТИКА — ИНТЕРАКТИВНАЯ ДЕМОВЕРСИЯ v0.1

Содержимое: index.html, manifest.webmanifest, icon.svg, sw.js.

Быстрый просмотр: открыть index.html на компьютере в браузере.
Для iPhone/PWA: разместить содержимое папки на отдельном HTTPS-домене или поддомене. Открыть адрес в Safari, Поделиться -> На экран «Домой».

Доступные функции демо:
- обзор расписания и статистики;
- создание записи, выбор свободного времени;
- подтверждение, перенос и полная отмена;
- карточки демонстрационных клиентов;
- макет видеоконференции.

Данные хранятся только в localStorage браузера. Нет сервера, регистрации, договоров, настоящих уведомлений, платежей, импорта и видеозвонков. Не использовать реальные персональные данные.

Важно: не размещать в существующей папке сайта psihofizika.ru без предварительного согласования. Рекомендуется отдельный тестовый поддомен.
